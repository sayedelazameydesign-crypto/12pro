# Attestations - Supply Chain Provenance (2026)

This folder contains build provenance attestations linking artifacts to repo+commit+workflow.

Generated by `.github/workflows/attestation.yml` and `release.yml` using:

- `actions/attest-build-provenance@v2` - SLSA provenance
- `actions/attest-sbom@v2` - SBOM attestation
- Docker buildx provenance + SBOM

Each attestation can be verified via:

```bash
gh attestation verify oci://ghcr.io/sayedelazameydesign-crypto/12pro:tag --owner sayedelazameydesign-crypto
```

See https://docs.github.com/en/actions/concepts/security/artifact-attestations
